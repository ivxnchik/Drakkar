# Как безопасно редактировать сайт Драккар-сервис

## Главное

Для обычных изменений **не редактируйте `index.html`**.

Почти весь текст сайта, цены, описания, контакты и подписи к фотографиям находятся в одном файле:

`content.js`

Именно его можно менять без вмешательства в HTML/CSS/JavaScript.

## Что можно менять в `content.js`

- телефон;
- title и description;
- заголовки и описания блоков;
- цены;
- названия услуг;
- тексты карточек лодок и аттракционов;
- подписи и `alt` фотографий;
- подписи в футере.

## Что НЕ нужно менять

Не меняйте в `index.html`:

- `class="..."`;
- `id="..."`;
- `src="img/..."`;
- блоки `<style>`;
- JavaScript внизу страницы.

Если нужно заменить фотографию — сначала положите новый файл в папку `img`, а затем лучше попросите внести замену отдельно.

## Безопасная схема через GitHub Desktop

1. Перед изменением убедитесь, что сайт сейчас работает.
2. Скопируйте папку репозитория или сохраните текущий ZIP как резервную копию.
3. Измените только `content.js`.
4. Откройте сайт локально и проверьте компьютер + телефон.
5. В GitHub Desktop посмотрите `Changes` и убедитесь, что изменился только ожидаемый файл.
6. Сделайте Commit.
7. Нажмите Push origin.
8. Если что-то сломалось — откатитесь к предыдущему коммиту.

## Если просите нейросеть внести изменения

Формулировка:

> Измени только `content.js`. Не меняй HTML, CSS, JavaScript и пути к изображениям. Сохрани структуру сайта.

Это сильно снижает вероятность случайно сломать верстку.
