Политика обработки персональных данных

Черновик для сайта в разработке. До публикации нужно вписать официальное имя оператора (ФИО ИП или наименование организации) и его адрес. Форма уже настроена на отправку заявок через FormSubmit на электронную почту.

Настоящий документ описывает обработку данных, которые посетитель добровольно указывает в форме на сайте «Драккар-сервис».

Какие данные и зачем обрабатываются

Форма может запрашивать имя и номер телефона; в поле комментария посетитель может добровольно описать свой запрос. Эти данные используются только для ответа на обращение, уточнения работ или комплектации изделия и связи по заявке.

Кто получает заявку

Форма передаёт заявку через FormSubmit (formsubmit.co) на адрес электронной почты, указанный в настройках сайта. FormSubmit участвует в передаче и обработке отправленных посетителем данных. Сервис уже используется для получения заявок; этот пункт объясняет посетителям, через какую систему проходит отправленная форма.

Срок обработки и защита данных

Данные используются в объёме, необходимом для ответа на обращение и дальнейшего взаимодействия по нему. Доступ к заявкам должен быть ограничен лицами, которым они нужны для ответа клиенту. Владелец сайта должен установить и указать фактический срок хранения заявок, а по его истечении удалить данные, если для их дальнейшего хранения нет другого основания.

Запросы по персональным данным

По вопросам обработки данных можно обратиться по телефону +7 978 984-27-79 или написать в MAX. Для размещения сайта здесь также нужно указать официальные реквизиты оператора и подходящий контакт для запросов по данным.
